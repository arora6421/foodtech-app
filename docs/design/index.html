M1.1 · Three visual directions

Every screen below comes from one shared template, rendered three times. The copy, dishes, prices, labels and information hierarchy are identical. Only the visual system differs. The shared copy follows Direction C's plain-copy rules, so the comparison stays fair. Direction C is built from the product owner's direction-c-DESIGN.md (reference only, not adopted). The dish shown is real engine output. You can drag the dish cards, replay the motion, and preview reduced motion.
